# Week 01: Welcome to technology and how the internet works

**CodeWithProf - NextGen Web, Cloud & AI Engineering Bootcamp - (Explorers) Cohort 1**

[Explorer track](../README.md) · [Cohort home](../../README.md)

This is the first week of the 16-week Explorer cohort for ages **9–14**. The fictional **StudyHub** website connects the reading, presentation, demos, lab, assignment, and project. Students explain how a browser finds a server, sends a request, and displays a response. No Python is needed for the Week 01 activities.

## Start here

1. Read the [student reading notes](Code_with_Prof_Week_01_Student_Reading_Notes.pdf) and use the [presentation](Code_with_Prof_Week_01_Fullstack_Journey.pptx) in class.
2. Work through the [demos in order](demos/README.md). The URL Explorer, live DNS explorer, and server conversation simulator open in a browser.
3. Complete the [DNS and URL assignment](assignment-guide-exp.md) with its [worksheet](lab/dns-phone-book-worksheet.md).
4. Create the [tech careers and internet poster](project-brief-exp.md) using the [starter](lab/careers-map-and-internet-poster.md).
