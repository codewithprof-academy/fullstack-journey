## The Scenario: Launching StudyHub! 🏫

The headteacher of a large secondary school has asked your engineering studio to build **StudyHub** — a brand-new platform where students check timetables, submit homework, and get revision help from a friendly AI bot.

Before the school buys the software, the governors want two things explained:
1. **Who is on the team building it?** They want to know that engineers, designers, security experts, and data specialists are all working together.
2. **How does StudyHub actually reach a student's screen?** They want a clear, colourful map showing how a message travels from a classroom laptop through the internet to a cloud server and back.

Your mission is to create a vibrant, informative poster that answers both questions!

## Requirements

### Part 1: The Tech Careers Map (Left Half of Poster)

Place **"Building StudyHub"** in a bold bubble in the centre of this section. Draw 8 branches extending outwards for each member of the engineering team:

| Branch Role | Description (1 sentence) | StudyHub Example Task |
|---|---|---|
| **Product Designer (UI/UX)** | Researches users and designs screen layouts | Chooses the colour scheme and simplifies homework buttons |
| **Frontend Developer** | Builds what students see and click | Writes code for the navigation menu and homework upload box |
| **Backend Developer** | Builds the hidden server engine and logic | Writes the program that verifies student passwords |
| **Cloud Engineer** | Sets up rented computers in data centres | Deploys StudyHub onto cloud servers so it never goes down |
| **DevOps Engineer** | Automates building, testing, and shipping updates | Makes sure new features can be updated safely every day |
| **Cybersecurity Specialist** | Protects accounts, grades, and private data | Tests the site to stop hackers and data leaks |
| **Data Analyst / Engineer** | Collects and organises learning statistics | Charts which subjects students study most often |
| **AI Engineer** | Builds and connects artificial intelligence models | Connects the StudyHub AI study buddy to give revision hints |

**Careers Star:** Put a big golden star ⭐ next to the **one job you would most like to do**, and write one sentence explaining why it appeals to you!

---

### Part 2: Draw the Internet (Right Half of Poster)

Draw and label the complete 8-step journey showing a student requesting `/homework`:

1. **The Client (Laptop / Browser):** Draw a laptop with a student typing `https://www.studyhub.example/homework`.
2. **The DNS Phone Book:** Show a phone book box that turns `studyhub.example` into IP address `203.0.113.10`.
3. **The Internet Highway:** Draw routers and cables carrying the request packet.
4. **The Request Arrow:** A labelled arrow: `Request: GET /homework`.
5. **The Server in the Cloud:** Draw a cloud bubble labelled: *"Someone else's computer in a secure data centre"*. Inside, draw the server computer.
6. **The Database:** Draw a filing cabinet or database cylinder holding the homework records.
7. **The Response Arrow:** A labelled arrow travelling back: `Response: 200 OK — Homework Page`.
8. **The Browser Screen:** The laptop drawing the finished homework page on screen.

---

### "Make It Yours" Creative Ideas 🎨

To make your poster stand out:
- Add colour codes for different parts of the journey.
- Create an invented superhero avatar or mascot for your engineering team.
- Add speech bubbles between the browser and the server.
- Add a "Did You Know?" box explaining why the cloud is not in the sky.

---

### 🛡️ Non-Negotiable Safeguarding Rules

- **First name or nickname only:** Write your first name on your poster. Never write your surname.
- **No private details:** Do not write your home address, phone number, or real school name.
- **No student photos:** Draw cartoons, use computer icons, or invent mascots. Never stick a real photo of yourself on the poster.
