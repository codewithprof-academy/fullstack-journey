# D2 — URL explorer (W01-ALL-LO4)

Open [the URL Explorer](index.html) in any browser (double-click the file — no server needed). Paste different URLs and watch the parts change colour. The app explains URL parts; it does not visit the address, so fictional `.example` lesson URLs are safe to explore.

Note: the browser hides the default port, so for `https://www.example.com:443/...` the port row shows "(default 443)".

**Suggested URLs to try live**
1. `https://www.example.com/` — the simplest possible URL
2. `https://www.example.com/courses/maths?level=beginner&page=2#reviews` — every part
3. `http://localhost:8000/api/time` — the server from D4 (a domain can be `localhost`, meaning "this computer")
4. `example.com` — shows the error: the browser's address bar adds `https://` for you; code does not.
